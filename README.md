These Scripts are an automation for to install Apss, Libraries and Dev Tools to my linux Distribution.
In these scripts I using apt an flatpak with flathub

Installing
- execute sudo sh post_install.sh

If code don't work on terminal command code  for open vscode is because we installed with flatpak, in this case use this steps:
- Open ~/.bashrc;
- add on the end page the command: alias code="flatpak run com.visualstudio.code"
- save file and then execute: source ~/.bashrc
